# Aman Stock AI V2

AI-powered starter Android app for Indian & global stock analysis.

## Build APK on GitHub
1. Upload the contents of this project to the `aman-stock-ai-v2` repository.
2. Open **Actions**.
3. Select **Build Aman Stock AI V2 APK**.
4. Run the workflow.
5. Download the generated `Aman-Stock-AI-V2-debug` artifact.

## Important
The current V2 contains a starter scoring algorithm. It does NOT predict future prices with certainty and is not financial advice. The next development step is connecting reliable live market data, technical indicators, news sentiment, backtesting, risk controls and a proper prediction model.
